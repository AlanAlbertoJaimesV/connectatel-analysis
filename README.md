# ConnectaTel Data Analysis & EDA

Este repositorio contiene el proyecto de limpieza de datos, análisis exploratorio (EDA), tratamiento de valores nulos (MAR), detección de outliers y segmentación de clientes para **ConnectaTel**.

## 📂 Contenido del repositorio

- `notebooks/connectatel_analysis.ipynb` -> Notebook principal con el flujo completo de análisis, estadísticas descriptivas, distribuciones, segmentación por uso y edad, y conclusiones ejecutivas.

## 🧠 Objetivo del análisis
- Validar la integridad de los datos en los perfiles de usuario y el historial de uso.
- Identificar y analizar valores faltantes condicionados (MAR).
- Evaluar distribuciones estadísticas y justificar la conservación de valores extremos (*power users*).
- Generar segmentaciones estratégicas por nivel de consumo y edad para apoyar la toma de decisiones comerciales.
